# FFmpeg MJPEG GUI v4 — FakePod 视频转换工具

把普通视频（mp4 / mkv / mov / avi / webm 等）转换为 FakePod 支持的 **AVI + MJPEG + MP3** 格式，输出适配 460×460 屏幕，支持竖版视频与正方形成片。

## 运行环境（必需）

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10 / 11（Windows 7 需 .NET Framework 4.x） |
| PowerShell | 5.1 或更高，Windows 自带，无需安装（可在开始菜单搜 `powershell` 验证） |
| FFmpeg | **必需**，需安装并加入 PATH，使 `ffmpeg -version` 在 PowerShell 中可运行 |
| 权限 | 无需管理员权限 |

### 安装 FFmpeg（首次使用）

1. 从 FFmpeg 官网或 [gyan.dev](https://www.gyan.dev/ffmpeg/builds/) 下载 Windows 构建版（选 full build 即可）
2. 解压到任意目录（如 `C:\ffmpeg`）
3. 把 `C:\ffmpeg\bin` 加入系统环境变量 **Path**（此电脑 → 属性 → 高级系统设置 → 环境变量）
4. 重新打开 PowerShell，输入 `ffmpeg -version` 能输出版本信息即成功

> 本工具只依赖 `ffmpeg.exe`，**不需要 ffprobe**（视频时长直接用 `ffmpeg -i` 解析）。

## 使用方法

### 启动

双击 `start.bat` 即可（等价于用 PowerShell 执行 `app.ps1`）。窗口固定大小、不可缩放。

### 转换流程

1. 点击 **"选择…"** 选择输入视频
2. 点击 **"另存为…"** 设置输出文件（默认生成在同目录的 `原文件名_460_24fps_MJPEG.avi`）
3. 按需调整视频 / 音频参数
4. （可选）点击 **"自动检测黑边"** 自动裁剪上下/左右黑边
5. （可选）勾选 **"方形裁切 460×460"** 输出纯正方形画面
6. （可选）在 **"片头/片尾裁剪"** 填入要去掉的秒数，点 **"预览去头尾"** 核对边界后转换
7. 点击 **"开始转换"**，完成后自动弹窗提示；界面底部会实时显示实际执行的 FFmpeg 命令

## 参数说明

### 视频参数

- **长边长度**：缩放目标（默认 460）。横版视频 → 宽 = 460；竖版视频 → 高 = 460，等比缩放、另一边自动取偶数
- **帧率 FPS**：默认 24；勾选方形裁切自动切为 20，取消勾选自动恢复 24
- **MJPEG q**：JPEG 质量（2 = 最清晰，31 = 最差），默认 5，越小越清晰、文件越大
- **使用裁剪参数**：手动裁剪黑边，格式 `crop=宽:高:X:Y`
- **自动检测黑边**：自动分析视频并填入裁剪参数（采样多段取多数结果，更可靠）
- **方形裁切 460×460**：先裁黑边，再把短边放大到 460、长边两侧居中裁掉，输出纯正方形画面；勾选自动采用 20FPS / q=5
- **片头/片尾裁剪**：去掉开头/结尾指定秒数（毫秒精度，如 `1.250` 秒）；点"预览去头尾"可拖动进度条查看任意位置画面，用"设为片头 / 设为片尾"直观选择边界，确定后自动回填数值；去片尾时自动探测视频时长
- **强制 yuvj420p**：4:2:0 采样，老设备兼容，默认开启

### 音频参数（MP3）

- **码率**：96k ~ 320k，默认 192k
- **采样率**：保持默认 / 44100 / 48000
- **声道**：保持默认 / 单声道 / 双声道

## 默认转换参数

- 容器 AVI，视频 MJPEG，音频 MP3
- 长边 460、24 FPS、MJPEG q=5、MP3 192k、yuvj420p
- 可自动检测黑边
- 可选方形裁切 460×460（勾选自动切为 20FPS / q=5）

## 常见问题

| 问题 | 解决 |
|---|---|
| 提示"未检测到 FFmpeg" | 安装 FFmpeg 并加入 PATH，重开工具 |
| 转换失败 | 把界面中"实际 FFmpeg 命令"复制到 PowerShell 手动执行，查看详细错误 |
| 竖版视频怎么转 | 默认模式输出宽 460 的竖幅；需要正方形成片就勾选"方形裁切" |
| 窗口打不开 / 无界面 | 确认系统 PowerShell 5.1 可用（`powershell.exe`） |

## 其他说明

- 纯本地转换，不联网，不上传任何文件
- 脚本为 UTF-8 带 BOM 编码，兼容中文 Windows 的 PowerShell 5.1
- 输出文件请放入 TF 卡的 `video` 文件夹供 FakePod 播放
